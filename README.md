# 🏥 HealthHub

HealthHub is a comprehensive, front-end only (HTML, CSS, JS) health and wellness web application designed to act as a complete personal health companion. It features an organic, humanistic design with a focus on usability, mental wellness, and physical health tools.

## ✨ Features

HealthHub is divided into 11 beautifully crafted sections, packed with interactive tools and information:

- **🧮 Health Calculators**: 6 fully functional interactive tools including:
  - **BMI Calculator** with animated gauge and health tips
  - **Calorie Calculator** with macronutrient breakdown
  - **Water Intake Calculator**
  - **Heart Rate Zones**
  - **Body Fat % Calculator**
  - **Ideal Weight Calculator**
- **🏋️ Exercise Guides**: Filterable workouts by category (Cardio, Strength, HIIT, Flexibility) and full workout plans.
- **🥗 Nutrition Guide**: A visual balanced diet breakdown, food nutrient database, superfoods spotlight, and sample meal plans.
- **🧠 Mental Health**: Features a live **breathing exercise tool**, daily affirmations, mental wellness tips, and emergency helplines.
- **🩹 First Aid**: Step-by-step emergency response guides with a built-in search filter.
- **🦠 Disease Awareness**: Information on common diseases and a basic interactive symptom checker.
- **😴 Sleep Health**: Sleep charts by age, practical tips, and an interactive bedtime routine checklist.
- **🧘 Yoga & Meditation**: Curated yoga poses and a customizable **Meditation Timer**.
- **📝 Blog**: A collection of health and wellness articles with modal reading views.
- **📊 Dashboard**: Local storage-based progress tracking, saving your latest calculator results and plotting a chart of your BMI history.

## 🎨 Design System

HealthHub utilizes a custom-built, premium **humanistic design system**:
- **Light Theme Default**: Warm creams, soft earth tones (sage green, terracotta, soft blue).
- **Typography**: Uses editorial **Lora** (Serif) for elegant headings and clean **Inter** (Sans-serif) for readable body text.
- **Animations**: Custom scroll-reveal animations, floating hero icons, and interactive hover states.
- **Responsive**: 100% mobile-friendly with a custom hamburger menu.

## 🚀 Getting Started

Since HealthHub is a pure front-end application with no backend dependencies, running it is incredibly simple:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/saurabhpandey0924-sys/healhhub.git
   ```
2. **Open the project:**
   Simply open `index.html` in any modern web browser.
   *(Alternatively, you can use a live server extension or `npx http-server` for a better development experience).*

## 🛠️ Technology Stack

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties (variables), Flexbox, CSS Grid, Keyframe animations.
- **Vanilla JavaScript (ES6)**: DOM manipulation, local storage persistence, interactive calculators.
